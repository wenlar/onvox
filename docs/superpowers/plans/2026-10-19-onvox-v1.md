# Onvox v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kısayol tuşuyla ChatGPT/Grok'un kendi web sesli modunu gizli bir WebView2 penceresinde açıp kapatan, tepside duran, imzalı ve kendini güncelleyen bir Windows programı.

**Architecture:** Tek Tauri v2 uygulaması. Seçili sağlayıcının sitesi gizli, odaksız bir pencerede sürekli açık durur; enjekte edilen `driver.js` sesli mod düğmesine basar ve olanları tek bir IPC komutuyla (`page_report`) Rust'a bildirir. Rust tarafında saf bir durum makinesi (`state.rs`) her olayı efektlere (bip, ikon, sesli modu başlat/durdur) çevirir; tepsi, kısayol, OBS göstergesi ve güncelleyici bu efektleri uygular. Ön yüz paketleyicisi yok: `ui/` altında düz HTML.

**Tech Stack:** Rust (stable 1.99), Tauri v2, tauri-plugin-global-shortcut / autostart / updater / process / opener, webview2-com (mikrofon izni), windows crate (PlaySoundW), ureq (uzak seçici dosyası), serde/serde_json.

**Spec:** `docs/superpowers/specs/2026-10-19-onvox-design.md`

## Global Constraints

- Program oyun sırasında **asla** pencere göstermez, odak almaz; görünür pencereler yalnızca ilk kurulum/giriş, "Yeniden giriş yap" ve "Kısayol tuşunu değiştir" menüden tıklanınca.
- Kısayol: Tauri global-shortcut (`RegisterHotKey`); düşük seviye klavye kancası (`WH_KEYBOARD_LL`) **kullanılmaz**. Varsayılan `Ctrl+Alt+Space`.
- Sohbet: program çalıştığı sürece aynı sohbet; program başlarken yeni sohbet; tepside "Yeni sohbet başlat".
- Sağlayıcılar: ChatGPT (`https://chatgpt.com/`), Grok (`https://grok.com/`). Tek WebView2 profili.
- Ses varsayılan çıkış cihazına gider (bipler dahil).
- OBS göstergesi yalnızca `127.0.0.1`'e bağlanır.
- Güncelleme: `https://github.com/wenlar/onvox/releases/latest/download/latest.json`; ~20 saatte bir + açılıştan sonra; kurulum asla `Starting`/`Listening` sırasında olmaz.
- Wenlar sunucusu yok, telemetri yok.
- Sadece Windows (x64), kurulum: NSIS. Kod imzalama: Azure Artifact Signing, `vars.AZURE_*` (repo'da tanımlı), `release` ortamı.
- Commit mesajları İngilizce; hiçbir commit'e AI atıf satırı eklenmez. Bakımcıyla sohbet Türkçe.
- Arayüz metinleri Türkçe ve İngilizce; Windows arayüz dili `tr` ise Türkçe, değilse İngilizce. *(plan kararı)*

## Review Focus

1. **Site sesli modu kendisi bitirir** (limit doldu, sessizlik zaman aşımı) → durum `Idle`'a döner, kapanış bibi çalar; ikon "aktif"te takılı kalmaz. Test: Task 3 `voice_ended_while_listening_goes_idle`.
2. **Tuşa hızlı iki kez basma** (`Starting` sırasında tekrar) → sesli mod durdurulur, `Idle`; geç gelen `VoiceStarted` raporu sesli modu yeniden "aktif" saymaz, `StopVoice` gönderir. Test: Task 3 `late_voice_started_after_cancel_stops_again`.
3. **Oturum düşmüş** (çerez süresi doldu) iken tuşa basma → hata bibi + kırmızı ikon, pencere açılmaz. Test: Task 3 `not_logged_in_report_is_error_without_window` + Task 9 kontrol listesi.
4. **İnternet yok / uzak seçici dosyası alınamıyor** → gömülü seçicilerle açılır. Test: Task 4 `remote_failure_falls_back_to_embedded`.
5. **Güncelleme hazırken konuşma sürüyor / program kapatılıyor** → konuşma sırasında kurulmaz; kapanışta önce sesli mod durdurulur. Test: Task 8 `install_blocked_while_active`.

Kurallar (`step`):

| Şu an | Olay | Sonra | Efektler |
|---|---|---|---|
| `Idle` / `Error(_)` | `Hotkey` | `Starting` | `Beep(On)`, `Icon(Active)`, `StartVoice` |
| `Starting` | `Report(VoiceStarted)` | `Listening` | — |
| `Starting` / `Listening` | `Hotkey` | `Idle` | `StopVoice`, `Beep(Off)`, `Icon(Idle)` |
| `Listening` | `Report(VoiceEnded)` | `Idle` | `Beep(Off)`, `Icon(Idle)` |
| `Starting` / `Listening` | `Report(Failed(f))` | `Error(f)` | `StopVoice`, `Beep(Error)`, `Icon(Error)` |
| `Starting` | `StartTimeout` | `Error(NoResponse)` | `StopVoice`, `Beep(Error)`, `Icon(Error)` |
| `Idle` / `Error(_)` | `Report(VoiceStarted)` | aynı | `StopVoice` |
| `Starting` / `Listening` | `NewChat` | `Idle` | `StopVoice`, `Beep(Off)`, `Icon(Idle)` |
| diğer her şey | | aynı | — |

  - `struct Selectors { schema: u32, chatgpt: Option<SiteSelectors>, grok: Option<SiteSelectors> }` — `None` = sağlayıcı v1'de yok
  - `fn embedded() -> Selectors` (`include_str!("../../selectors.json")`)

`driver.js` davranışı:
- `start(sel)`: `logged_out` seçicilerinden biri varsa → `failed/not_logged_in`; `limit_texts`'ten biri `document.body.innerText`'te varsa → `failed/limit_reached`; `start_voice`'tan ilk bulunanı tıkla, yoksa → `failed/voice_button_missing`; `voice_active` görünür olunca → `voice_started`. - `stop(sel)`: izlemeyi durdurur (rapor göndermeden), `stop_voice`'tan ilk bulunanı tıklar.
- Seçiciler koda değil, `start`/`stop`'a argüman olarak `JSON.stringify` ile verilir; uzak dosyadaki metin asla kod olarak çalıştırılmaz.
